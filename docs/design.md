# 页面设计与范围

设计基准：本次生成的 Prompt Gallery 完整桌面概念图，1536 × 1024。

采用白色 `#FFFFFF` 背景、正文 `#20221F`、深绿色 `#244B3F`、分割线 `#E5E6E8`。英文字标使用 Georgia 衬线体，中文使用系统无衬线体；不加载外部字体。间距以 6/12/18/24/32/48 为主，图片圆角 7px，不加卡片阴影。

首屏结构：简洁字标 → 两行中文标题与说明 → 搜索 → 分类 → 图片网格。四列桌面、三列中等屏幕、两列手机。详情为大图与提示词的双栏弹窗，手机改为上下排列。

首屏文案：

- Prompt Gallery.
- 图片与提示词，仅此而已。
- 让好图片，也有迹可循。
- 浏览图片，发现提示词。选一张喜欢的，复制灵感的起点。
- 搜索图片、风格或提示词…
- 全部、摄影与人像、海报与排版、产品与商业、插画与艺术、空间与建筑、图表与信息、更多。

有意调整：使用用户已有的真实图片，替换概念图中的示意图片；数量写作“542 组图片”，因为其中一条提示词对应七张配图；“更多”展开其余五个实际分类。原文提示词在详情完整显示，多图组可切换，复制不包含额外标签或来源说明。

运行范围只有静态图片和 JSON，没有生成服务、登录账号、数据库或其他运营模块。
